# LocalAgent 0.1_beta

Десктопный ИИ-агент для Windows. Electron-окно на твоём ПК.

Видит диски, папки, скриншоты и архивы этого компьютера.
Копирует, удаляет, создаёт, переносит, правит, пакует zip.
Экран — кнопка в шапке, можно выключить.
Голос — микрофон (скажи команду) и голосовой чат (слушаю → отвечаю вслух).

## Прямая ссылка на скачивание исходников

https://github.com/MrAIinator/LocalAgent/archive/refs/heads/main.zip

Или кнопка **Code → Download ZIP** на странице репозитория.

## Что нужно

1. [Node.js 20+](https://nodejs.org)
2. По желанию: [Ollama](https://ollama.com) или LM Studio

## Запуск на Windows

1. Распакуй архив.
2. Открой папку `LocalAgent-main` (или `LocalAgent-0.1_beta`).
3. Дважды нажми `LocalAgent.bat`.
4. Первый запуск ставит зависимости и Electron — подожди 1–3 минуты.
5. Откроется окно LocalAgent.

Если Node не установлен, скрипт сам откроет страницу загрузки.

## Локальная модель

Настройки → Ollama (`http://127.0.0.1:11434/v1`) или LM Studio (`http://127.0.0.1:1234/v1`).
В Electron CORS не нужен.

```bash
ollama pull qwen2.5:7b
```

## Голос

- Микрофон в шапке: нажал — говори — нажал ещё раз — отправил.
- «Чат голосом»: после ответа агент говорит вслух и снова слушает.

## Что умеет

- диски и избранные папки (Дом, Документы, Загрузки, Скриншоты, Captures)
- просмотр текста, картинок, zip
- создать / скопировать / перенести / удалить / распаковать zip / упаковать zip
- поиск по именам и содержимому
- захват экрана (вкл/выкл)
- голосовой ввод и голосовой чат

Удаление спрашивает подтверждение.
